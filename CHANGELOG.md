## [Unreleased]

Audit remediation across all 11 packages. Generated by `scripts/release.js` on
the next release; recorded here in full because several changes are breaking.

### 💥 Breaking

- **`Model.guarded` now defaults to `['*']`** (was `['id']`), matching Laravel:
  nothing is mass-assignable until the model declares `fillable`. Set
  `static guarded = []` to restore the old behaviour, or `strictFill = true` to
  throw `MassAssignmentException` instead of dropping keys silently.
- **Comparison operators are whitelisted.** An operator outside the allowed list
  throws instead of being interpolated into SQL. Use `whereRaw()` for the rest.
- **`Collection.groupBy` / `keyBy` / `pluck(v, k)` and `QueryBuilder.pluck(c, k)`
  return `Map`s**, not plain objects: object keys coerce to strings and a value
  of `__proto__` mis-keys.
- **Pivot data moved from the `_pivot` attribute to a relation accessor**
  (`model.pivot`, renameable with `.as()`). As an attribute it serialised into
  `toJSON()` and was written back to the main table on the next `save()`.
- **`Blueprint` emits portable default markers** (`{expr:'uuid'}`) rather than
  Postgres SQL; drivers render them. `.unique()` now registers a named
  table-level index instead of an inline `UNIQUE`.
- **`Schema.drop`/`dropIfExists` and `Model.truncate` no longer cascade.** Pass
  `{ cascade: true }` explicitly.
- **`@eloquentjs/cli`'s entry point no longer executes on import** — it exports
  `run(argv)`; `bin/eloquent.js` is the CLI.
- **`RealtimeClient` moved to the `./client` subpath** and no longer imports
  anything from Node.
- `EventEmitter.emit()` and `HookRegistry.fire()` return a boolean (false when a
  listener cancelled). `HookRegistry.register()` rejects unknown event names.
- `unique`/`exists` validation rules only run on the async path, and no longer
  fail open on a database error. Unknown rule names throw.
- `pg` and `mongodb` are no longer *optional* peers — they are imported
  statically, so the package cannot load without them.

### 🐛 Bug Fixes

- **Transactions wrapped nothing.** Model writes inside `transaction()` ran on a
  different pooled connection and were already durable when the rollback
  happened. Added `DB.transaction()`, a `transaction(fn)` resolver method on all
  three drivers, savepoints for nested calls, and an `AsyncLocalStorage` scope so
  writes participate without threading anything through call sites.
- **MongoDB updates and PK lookups silently no-oped.** `id` is now an alias of
  `_id` on every filter, sort, projection and update path, so the default
  `primaryKey = 'id'` works: `find()` matches and `save()` writes.
- `whereNotBetween` on MongoDB was unsatisfiable (`{$lt, $gt}` ANDed on one
  field); it now uses `$or`. LIKE patterns escape regex metacharacters.
- `save()` set `updated_at` before computing dirtiness, so every save issued an
  UPDATE. It now returns early when nothing changed.
- `wasChanged()` could never return true; it now reports what the last save
  wrote, with `getChanges()` alongside.
- `belongsToMany().where()/orderBy()/limit()` collected constraints and never
  applied them, returning every related row. Relations are real query builders
  now — every builder method reaches the database.
- `sync()` compared numeric DB keys to string `Object.keys()`, so every sync
  detached and re-attached everything. `detach([1,2])` compared a column to an
  array.
- `hasManyThrough` ignored eager-load constraints and dropped `localKey`/
  `throughKey`.
- `paginate()`/`count()` on a grouped query reported the first group's size.
- `@eloquentjs/api`: nested resources were unreachable (`startsWith` dispatch);
  middleware that answered the request hung forever; `fastifyPlugin` threw
  `FST_ERR_CTP_ALREADY_PRESENT`; `trashed`/`restore` skipped the policy;
  pagination input was unclamped (`NaN` limit, negative `OFFSET`); sorting was
  opt-out while filtering was opt-in.
- Validation: pipe syntax (`'required|email'`) iterated the string's characters;
  rule parameters were truncated at the first colon (`regex:^a:b$`); `min`/`max`
  compared string length for numeric fields; `nullable` was a no-op; unknown
  rules passed silently.
- GraphQL: Subscription resolvers were registered without a Subscription type;
  every prototype method became an invoked field; relations resolved one query
  per row; the async iterator dropped consumers, never settled on `return()` and
  had no `throw()`; the JSON scalar could not parse object literals.
- `codegen` derived fields from `casts` alone, so a model with `fillable` and no
  casts generated empty types. `graphql.fields` silently un-hid `hidden` columns.
  Class-based casts threw.
- One pluraliser everywhere: REST said `/categories` while GraphQL said
  `categorys` and the WebSocket channel was `categorys`.
- `pgsql`'s `alterTable` ignored indexes and foreign keys entirely; FK/index
  names now come from core so migrations are portable.
- `Blueprint`: `unsignedInteger('x').unsigned()` threw; `.index()` on a column
  created nothing; `cascadeOnDelete()` before `constrained()` did nothing.
- `CastRegistry.serialize` created two instances and returned an unbound method.
- Realtime: any socket could inject events into any channel; `authHandler`
  treated `false` as authorised; `close()` leaked listeners and the HTTP server.
- Model's Proxy had no `deleteProperty`/`ownKeys` traps, so `Object.keys(user)`
  and `{...user}` came back empty and `delete user.name` did nothing.
- `Collection`: `whereIn`/`sum`/`min`/`max` bypassed casts and accessors while
  `where()` applied them; `each()` ignored a `false` return; `sum()` with no key
  returned 0.
- Factories went through mass assignment, which with the new `guarded` default
  would have written nothing.

### ✨ Features

- `DB` facade: `DB.transaction()`, `DB.table()`, `DB.raw()`, `DB.inTransaction()`.
- Relationship queries: `whereHas`, `orWhereHas`, `whereDoesntHave`, `has`,
  `doesntHave`, `withCount`, `withSum`, `withAvg`, `withMax`, `withMin`,
  `withExists` — batched, one aggregate query per relation.
- QueryBuilder: `clone`, `whereColumn`, `whereTime`, `whereExists`, every
  `orWhere*` variant, group-negating `whereNot`, `when`/`unless`/`tap`,
  `upsert`, `updateOrInsert`, `insertGetId`, `sole`, `findOr`, `lazy`/`cursor`,
  `each`, `chunkById`, `simplePaginate`, `reorder`, `groupByRaw`, `havingRaw`,
  `havingBetween`, `lockForUpdate`, `sharedLock`, `dump`. `where(col, null)` now
  means `IS NULL`, and bulk `update()` touches `updated_at`.
- Model: `saving`/`saved`/`retrieved` events, cancellable hooks, `Model.observe`,
  `Model.on`, `scope()`, `getChanges`, `replicate`, `is`/`isNot`, `touch`,
  `push`, `load`/`loadMissing`, `withoutTimestamps`, `saveQuietly`, `upsert`,
  static `increment`/`decrement`, `attributes` defaults, `withRelations`,
  `touches`, `resolveRouteBinding`.
- Relations: `hasOneThrough`, `morphToMany`, `morphedByMany`, `withDefault`,
  `withTimestamps`, `as()`, `wherePivot`, `withPivotValue`,
  `syncWithoutDetaching`, `firstOrCreate`/`updateOrCreate`, `getQuery()`, and
  `ModelRegistry.morphMap()` so a class rename can't orphan polymorphic rows.
- Casts: `hashed` (+ `verifyHashed`), `immutable_date`, `AsEnum`.
- Collection: `sole`, `contains`, `partition`, `median`, `implode`, `random`,
  `shuffle`, `modelKeys`, `load`/`loadMissing`.
- Factory: `sequence`, `has`, `for`, `raw`, `recycle`, `createQuietly`; `count`
  > 1 returns a `Collection`.
- Validation: pipe syntax, `date_format`, `not_regex`, `accepted`, `distinct`,
  `filled`, `present`, `required_unless`, real `items.*.price` wildcard
  expansion, `after()` hooks, `addError()`, `before:`/`after:` against another
  field.
- Blueprint: `->change()`, `foreignUuid`, `mediumText`, referential-action
  helpers, real column `.index()`.
- `Expr.uuid` / `Expr.now` / `Expr.today` portable default markers.
- `Attribute.make({ get, set })` — Laravel 9-style attribute accessors,
  declared as a getter/field: `get fullName() { return Attribute.make({...}) }`.
  `set` may return an object to write several columns at once.
- Casts: `AsCollection` (JSON column read back as a `Collection`),
  `AsArrayObject` (JSON object column read back as a plain mutable object,
  `null` reads as `{}`).
- Relations: `hasOneOfMany`, and `latestOfMany()`/`oldestOfMany()` on `hasOne`
  — picks the single latest/oldest related row, for both `.get()` and eager
  loading.
- `Prunable`: override `static prunable()` with a query and call
  `Model.prune()` to bulk-delete matching rows in chunks, firing a new
  `pruning` hook per row.
- `QueryBuilder.cursorPaginate(perPage, cursor)` / `Model.cursorPaginate()` —
  keyset pagination that stays stable while rows are inserted/deleted
  elsewhere in the table, unlike offset paging.
- `QueryBuilder.union()`/`unionAll()` — SQL `UNION`/`UNION ALL` across two
  queries (sqlite/pgsql only; MongoDB throws, since `find()` has no
  equivalent).

### 🔧 Chores

- ESLint added (correctness rules only) and wired into `npm run lint` and CI;
  `npm run check` runs lint + typecheck + tests.
- `tsconfig.base.json`: `noEmitOnError: true`, `noImplicitReturns`,
  `noFallthroughCasesInSwitch` — declarations are no longer emitted from JSDoc
  that fails to type-check.
- Coverage floor enforced in `jest.config.js`. New suites for relations,
  transactions, GraphQL, Factory/Schema and the validator fixes: 1146 tests
  across 22 suites (was 993/18), relations coverage 0.95% → 55%, GraphQL 0% → 69%.
- `prepublishOnly: npm run build` and `repository.directory` on every package.
- Internal `@eloquentjs/*` cross-dependencies use a range that admits patches; a
  caret on `0.0.x` pinned the exact version and forced lockstep republishing.
- One written resolver contract: `RESOLVER.md`, the `ModelResolver` typedef and
  `conformance.js` now agree on what is required and what is optional.

## [1.0.0] — 2025-03-15

### ✨ Features

- **codegen:** `introspect(ModelClass|descriptor)` — normalises any Model into a `ModelSchema` with per-field `gqlType`, `tsType`, `openApiType`; auto-detects relations, scopes, timestamps, softDeletes
- **codegen:** `introspectAll([...])` — batch introspection
- **codegen:** `generateGraphqlSDL` / `generateGraphqlSchema` — GraphQL SDL fragments and full standalone `.graphql` files
- **codegen:** `generateTypeScriptTypes` / `generateTypeScriptFile` — TypeScript interfaces + `CreateInput`, `UpdateInput`, `WhereInput`, `PaginationMeta`, `PaginatedResult<T>`
- **codegen:** `generateOpenApiSpec` — full OpenAPI 3.0 spec mirroring `@eloquentjs/api` routes with query params, soft-delete paths, error schemas
- **codegen:** `generateModelStub`, `generateMigrationStub`, `generateFactoryStub`, `generateSeederStub` — source stubs with faker hints and typed column generation from schema
- **codegen:** `loadModelsFromDir`, `loadModelsByName`, `renderGraphql`, `renderTypeScript`, `renderOpenApi`, `renderStubs` — render engine for file-based generation
- **graphql:** Refactored to use `@eloquentjs/codegen` internally for SDL generation
- **graphql:** New `buildSchemaFromDir(modelsDir, options)` — auto-loads all model files from a directory
- **cli:** `generate:graphql` — generates `schema.graphql` from live model files
- **cli:** `generate:types` — generates `models.d.ts` from live model files
- **cli:** `generate:openapi` — generates `openapi.json` or `openapi.yaml` from live model files
- **cli:** `make:model` and `make:migration` now delegate to codegen stubs when available, with inline fallback
- **core:** Base `Model` class with WeakMap/Proxy architecture for private state
- **core:** Full fluent `QueryBuilder` with 40+ where/order/join/aggregate methods
- **core:** `Collection` with 25+ functional methods (pluck, groupBy, chunk, mapInto, etc.)
- **core:** `CastRegistry` with built-in casts: boolean, integer, float, decimal, json, array, date, datetime
- **core:** Custom cast classes with `get`, `set`, `serialize` hooks
- **core:** `EventEmitter` — async global event bus with wildcard support
- **core:** `HookRegistry` — model lifecycle hooks and observer pattern
- **core:** `Schema` builder — create/alter/drop tables with a fluent column API
- **core:** `Validator` — rule-based validation with 15+ built-in rules
- **core:** `Pipeline` — composable data transformation pipes (class or function)
- **core:** `Factory` + `Seeder` — test data generation with state support
- **core:** `ConnectionRegistry` — named multi-connection management
- **core:** `RelationRegistry` — hasOne, hasMany, belongsTo, belongsToMany, hasManyThrough, morphTo, morphMany
- **core:** Soft deletes — `delete()`, `restore()`, `forceDelete()`, `withTrashed()`, `onlyTrashed()`
- **core:** Global and local query scopes with `withoutGlobalScope()`
- **core:** Accessors (`getXxxAttribute`) and Mutators (`setXxxAttribute`)
- **core:** Dirty checking — `isDirty()`, `getDirty()`, `getOriginal()`, `wasChanged()`
- **core:** `paginate()` — returns `{ data, meta: { total, per_page, current_page, last_page, has_more } }`
- **core:** `chunk()` — memory-efficient batch iteration
- **pgsql:** Full PostgreSQL driver with connection pooling via `pg`
- **pgsql:** Transaction support with automatic rollback on error
- **pgsql:** Complete SQL generation: SELECT, INSERT, UPDATE, DELETE, JOINs, GROUP BY, HAVING
- **pgsql:** Correct `$N` parameterized query numbering across WHERE, HAVING, LIMIT, OFFSET, UPDATE, INCREMENT
- **pgsql:** Schema builder mapped to PostgreSQL DDL
- **mongodb:** MongoDB driver using the official `mongodb` driver
- **mongodb:** ObjectId ↔ string `id` mapping
- **mongodb:** Support for nested document queries and array contains
- **realtime:** WebSocket server using `ws`, Pusher wire-protocol compatible
- **realtime:** `broadcastFrom(ModelClass)` — auto-broadcast model lifecycle events
- **realtime:** Public, private, and presence channels
- **realtime:** `RealtimeClient` — lightweight browser/Node client with auto-reconnect
- **realtime:** Channel auth handler for Express/Fastify
- **graphql:** `buildSchema([ModelClass, ...])` — auto-generates complete GraphQL SDL + resolvers
- **graphql:** Queries: `find`, `list` (paginated), `count`
- **graphql:** Mutations: `create`, `update`, `delete`, `upsert`, `restore`, `forceDelete`
- **graphql:** Subscriptions via async iterators over EventEmitter
- **graphql:** Relay and offset pagination modes
- **graphql:** Per-model `static graphql` config — hide fields, disable operations, middleware
- **graphql:** JSON and DateTime custom scalars
- **api:** `resource(ModelClass, opts)` + `apiRouter([...])` for Express
- **api:** `fastifyPlugin` for Fastify
- **api:** Auto-routes: index, show, store, update, patch, destroy, trashed, restore
- **api:** Nested resources, query filtering, search, sort, eager loading via `?with=`
- **api:** Policy-based authorization, response transformation, custom filters
- **api:** Automatic validation from `Model.rules`
- **cli:** `eloquent init` — scaffold config, directories, seeder, `.env.example`
- **cli:** `eloquent make:model` with `--migration`, `--factory`, `--seed`, `--all`, `--soft-deletes`
